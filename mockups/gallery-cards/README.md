# Макеты карточек галереи

Макеты ленты карточек работ — **только концепт, в проект не встроены**. Стек тот же, что в `apps/web`: React 19 + Vite 7 + TypeScript, живые GLSL-превью на WebGL 2 (один fragment pass, `mainImage`-стиль, `uTime`/`uRes`), шрифты Lora + Manrope.

## Запуск

В этой папке (зависимости берутся из корневого `node_modules`):

```powershell
npm run dev        # http://127.0.0.1:5178
npm run check      # проверка типов
npm run build      # production-сборка в dist/
```

Внизу страницы — переключатель четырёх макетов (или клавиши 1–4).

## Версии

| Версия | Десктоп (веб) | Мобильная (приложение) |
|---|---|---|
| **A · Минимализм** | Стеклянные карточки: изображение шейдера маской растворяется в поверхности карточки, акцентное свечение от палитры работы, лёгкий 3D-наклон при наведении | Та же карточка + **интерактив «покрутить в руках»**: перетаскивание пальцем/мышью с инерцией, параллакс шейдера внутри карточки, гироскоп телефона (кнопка «Покрутить в руках», на iOS — запрос разрешения) |
| **B · Галерея (Three.js)** | Реалистичный 3D-зал: **длинная стена галереи**, которую проматывает пользователь. Живые шейдеры — настоящие картины в золотых багетах с паспарту и латунными табличками, настенные лампы со световыми конусами, паркет, скамейки, надпись у входа. Прокрутка колесом/перетаскиванием (с инерцией), взгляд мышью, клик по картине — камера подъезжает и открывает карточку с описанием (Esc — назад) | Тот же 3D-зал в телефоне: палец — прогулка вдоль стены, тап — рассмотреть картину, гироскоп — осмотреться. Внизу карточка-подпись с названием/автором/тегами |

На узком экране (≤760px) мобильные макеты показываются во весь экран; на широком — в корпусе телефона.

## Структура

```
src/
  App.tsx               переключатель макетов
  data.ts               работы ленты (заголовки, авторы, теги, акценты)
  shaders.ts            6 живых GLSL-сцен (fluid, monolith, particles, horizon, fractured, worlds)
  ShaderCanvas.tsx      WebGL 2 превью: пауза вне экрана, prefers-reduced-motion, dpr-кап
  Tilt.tsx              3D-покрутка карточки (A): pointer + deviceorientation, CSS-переменные --rx/--ry/--mx/--my
  PhoneShell.tsx        корпус телефона, статус-бар, нижняя навигация, кнопка гироскопа
  three/
    GalleryWall.tsx     3D-зал на Three.js (B): стена, рамы, лампы, таблички, камера, ввод
    artMaterial.ts      живые GLSL-сцены как RawShaderMaterial-картины
    textures.ts         процедурные текстуры: обои, паркет, багет, латунь, свет
  views/                DesktopMinimal, DesktopGallery, MobileMinimal, MobileGallery
  styles/               base + по файлу стилей на каждый макет
```

Данные и статистика — вымышленные, для вида. Иконки — инлайновый SVG. Всё живёт только в этой папке и не затрагивает код сайта и Android-приложения.
