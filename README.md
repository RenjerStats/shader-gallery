# Shader Gallery

Пилотная версия галереи живого цифрового искусства. Веб-приложение позволяет создать GLSL-работу, опубликовать её, смотреть, настраивать, комментировать, сохранять и делать ремиксы. Android-приложение показывает общую ленту с поиском, категориями и подборкой, поддерживает аккаунт, сохранения, подписки, реакции и комментарии. Выбранную версию оно показывает через GLES 3 и предлагает системную установку живых обоев. Редактор кода доступен только в настольной версии сайта. Исходный прототип сохранён в `dist/`.

## Веб и локальный сервер

Требуется Node.js 22 или новее. В корне проекта:

```powershell
npm ci
npm run dev
```

Откройте `http://127.0.0.1:4173`. Данные аккаунтов и работ сохраняются в `data/pglite/`. Для проверки двух участников зарегистрируйте два разных аккаунта в разных профилях браузера. Публикация, комментарии, сохранения и подписки общие для всех клиентов, которые открывают этот сервер.

Проверки и production-сборка веба:

```powershell
npm test
npm run build
npm run start
```

`npm run start` раздаёт папку `build/` и API с одного процесса. Для публичного пилота нужен HTTPS-прокси, резервное копирование `data/` и `PUBLIC_ORIGIN=https://ваш-домен`; текущий сервер предназначен для закрытого пилота на одном узле. Статический хостинг из `.openai/hosting.json` по-прежнему показывает старое демо `dist/` и не обслуживает новый API.

Остановив сервер, можно проверить восстановление базы: `node server/backup.mjs backup data/pglite backups/snapshot.tar.gz`, затем `node server/backup.mjs restore backups/snapshot.tar.gz data/restored`. Скрипт проверяет SHA-256 архива и не перезаписывает существующий каталог. Архив содержит пользовательские данные: храните его вне публичного веб-каталога.

## Android

Исходники находятся в `apps/android/`. Нужны Android SDK 35, JDK 17 и Gradle 8.13. Для сборки откройте этот каталог в Android Studio или выполните:

```powershell
$env:JAVA_HOME='C:\path\to\jdk-17'
$env:ANDROID_HOME="$env:LOCALAPPDATA\Android\Sdk"
gradle :app:assembleDebug
```

APK появится в `apps/android/app/build/outputs/apk/debug/app-debug.apk`. В приложении можно указать адрес галереи или открыть ссылку на работу; адрес запоминается. Debug-сборка по умолчанию ищет локальную галерею на `http://127.0.0.1:4173`. Ссылка «Открыть на Android» на странице работы передаёт конкретную версию и адрес сервера. Приложение принимает HTTPS-адреса; для проверки по USB разрешён только `http://127.0.0.1` через `adb reverse tcp:4173 tcp:4173`. Для лент «Подписки» и «Сохранённое», реакций и комментариев нужен вход в тот же аккаунт. Настройки и выбранный пакет хранятся на телефоне. После загрузки пакета обои не требуют сети.

Используемый профиль: WebGL 2 / GLES 3, один fragment pass, `mainImage`, `iTime`, `iResolution`, `iMouse`, `iTilt`, до 12 пользовательских параметров `float` и `color`. Текстуры, каналы и несколько проходов не поддерживаются. Пакет описан в `packages/shader-contract/v1.schema.json`.

## Текущий статус

Код веба и debug APK собираются, семь интеграционных тестов и восстановление резервной копии проходят. В тесте 105 работ проходят через постраничную выдачу без дубликатов. Лента, поиск и переход к работе проверены на физическом Android-устройстве; гостю показывается вход перед сохранением. Основной путь веба ранее проверен двумя аккаунтами, а текущая версия повторно проверена в браузере на настольной и мобильной ширине. Предпросмотр одного пакета ранее работал на двух физических телефонах с Adreno и Mali. Установка настоящих обоев, offline и lifecycle установленного WallpaperService, датчики, нагрузочные измерения, публичный HTTPS-хост и пилот с людьми ещё нужны для приёмки MVP по `docs/03-mvp-plan.md`. Подробности — в `docs/mvp-status.md` и `TESTING.md`.
